# Site da Larissa

Site novo para a Larissa, amiga do Cesar. Pasta criada vazia em 11/11/2026; ainda não existe repositório no GitHub.
Responda sempre em português do Brasil, com linguagem simples.

## Antes de começar
Pergunte ao Cesar (ou à Larissa) o que ainda não se sabe:
- Para que é o site (loja, portfólio, negócio, evento, pessoal...) e o que precisa ter.
- Nome, textos, fotos, logo, cores e redes sociais.
- Se vai vender algo ou só apresentar.
- Onde publicar (sugestão: GitHub Pages, de graça, como a Farmaura).

## Regras
- Pergunte antes de publicar ou de dar push no GitHub (a autorização automática vale só para a Farmaura).
- Não use dados pessoais da Larissa (telefone, endereço, e-mail) sem ela autorizar.
- Não invente avaliações, números ou certificações.
- Teste no celular antes de publicar.
